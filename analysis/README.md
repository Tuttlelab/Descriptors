# Trajectory & Post-Processing Analysis Scripts

This directory contains system-specific post-processing and plotting scripts used to analyze specific peptide assembly trajectories (FF, RF, WI) from the *Faraday Discussions* (2025) study.

## Key Scripts

- `evolution_FF.py`, `evolution_RF.py`, `evolution_WI.py`: Compute structural evolution timelines for Diphenylalanine (FF), Arg-Phe (RF), and Trp-Ile (WI) systems.
- `dominant_FF.py`, `dominant_RF.py`, `dominant_WI.py`: Extract dominant aggregate shape distributions.
- `combined_plot_WI.py`: Combined multi-panel trajectory visualizations.
